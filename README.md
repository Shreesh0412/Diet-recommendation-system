# AI-Based Diet Recommendation System
## Overview
This project is a CLI-based application that recommends diet plans based on user goals such as weight loss, gain, or maintenance.

## Problem Statement
Many people, especially students, do not have proper guidance on what to eat according to their health goals. 
This leads to unhealthy eating habits and poor lifestyle choices.

## Features
- Personalized diet plan (Breakfast, Lunch, Dinner, Snacks)
- Calorie estimation
- Health warning system for unhealthy junk food habits

## Technologies Used
- Python
- Rule-Based Systems (Decision Making using conditions)

## How to Run
1. Clone the repository
2. Run: cli.py

## Sample Input
```Diet Recommendation System
Enter goal: loss
Enter weight: 60
```
 

## Sample Output
```Your Diet Plan
Recommended Calories: 1500 kcal
Breakfast: Oats + Fruits
Lunch: Brown rice + Dal + Vegetables
Dinner: Chapati + Sabzi
Snacks: Nuts / Green Tea
```
