# AI-Based Diet Recommendation System
## Overview
This project is a CLI-based application that recommends diet plans based on user goals such as weight loss, gain, or maintenance.

## Features
- Personalized diet plan
- Calorie estimation
- Health warning system
- Junk food warning

## Technologies Used
- Python

## How to Run
1. Clone the repository
2. Run: python cli.py

## Example Input
Goal: loss  
Weight: 60  

## Output
Diet plan with meals and calorie estimate
